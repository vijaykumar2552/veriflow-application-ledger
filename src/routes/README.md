# Application routes

TanStack Start uses file-based routing. The application routes are:

| File                     | URL                 |
| ------------------------ | ------------------- |
| `index.tsx`              | `/`                 |
| `applications.index.tsx` | `/applications`     |
| `applications.$id.tsx`   | `/applications/:id` |
| `documents.tsx`          | `/documents`        |
| `validation.tsx`         | `/validation`       |
| `review.tsx`             | `/review`           |
| `rules.tsx`              | `/rules`            |
| `audit.tsx`              | `/audit`            |
| `reports.tsx`            | `/reports`          |
| `settings.tsx`           | `/settings`         |

`__root.tsx` defines the shared application shell. `routeTree.gen.ts` is generated by TanStack Router and should not be edited by hand.
